# 🐛 Bug Hunt

### Find the bug. Understand the failure. Prove the fix.

Bug Hunt is an interactive developer debugging lab designed to simulate a real-world software debugging workflow.

Instead of simply asking users to solve a programming problem, Bug Hunt guides them through the complete debugging process:

**Choose Challenge → Investigate → Diagnose → Fix → Verify → Engineering Report**

The project focuses on debugging mindset, root-cause analysis, engineering decisions, and verification rather than complex programming.

---

## 🎯 Why Bug Hunt?

In real software development, engineers don't always write code from scratch.

A large part of engineering involves:

- Understanding existing code
- Investigating unexpected behaviour
- Reading error messages and logs
- Identifying the root cause
- Choosing a safe fix
- Testing the solution
- Documenting what happened

Bug Hunt turns this process into an interactive experience.

The goal is to demonstrate **how a developer thinks when something goes wrong**, not just whether they can write complicated code.
